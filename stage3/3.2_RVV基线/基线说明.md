# 3.2 标准RVV组合指令基线

真实实现位于 [generate.py](generate.py) 的BASE序列。输入为v1/v2，结果为v3；入口e8/m1/VL8/tu/mu，v6提前完整清零：

```asm
vmv1r.v    v3, v6
vwmul.vv   v4, v1, v2
vsetivli   zero, 8, e16, m2, tu, mu
vwredsum.vs v3, v4, v6
vsetivli   zero, 8, e8, m1, tu, mu
```

1. 整寄存器复制零值，确保目标高96位也清零。
2. signed int8扩宽乘法产生int16乘积；v4/v5为对齐的宽化寄存器组。
3. 切换SEW/LMUL，以16位元素解释8个乘积。
4. 用signed扩宽归约累加成32位结果，写入目的第0元素。tu使其余位保留前面清零的值。普通16位归约会在边界输入溢出，不能替代此处的宽化归约。
5. 恢复与vdot相同的e8/m1/VL8状态。

完整结果等价测试 `rvv_equivalence` 覆盖42组：10组定向＋32组固定随机，包括极值、零、混合符号和高64位干扰。通过独立软件golden逐字节检查整个目标128位，而不是仅检查最低32位。

性能程序分别运行1、32、128次点积。vdot版本每轮1条自定义指令，RVV版本每轮上述5条；两边都有相同的递减和循环分支、输入初始化及最终检查。源固定，不存在跨迭代vdot结果RAW链；RVV单次组合内部存在乘法到归约的依赖。

基线契约是每次调用产生完整128位结果并恢复配置，且允许使用v4/v5/v6临时寄存器；这是可执行直接基线，不宣称是批量重排后的最优RVV程序。原循环不等同于矩阵乘法或实际应用。
