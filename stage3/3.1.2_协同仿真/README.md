# 3.1.2 协同仿真材料

```text
3.1.2_协同仿真/
├── programs/
│   ├── generate.py               8组功能套件生成器
│   ├── common.S                  启动、配置及完整结果检查
│   ├── link.ld、Makefile         链接与镜像构建
│   └── build/                    本地生成的汇编、镜像、反汇编
└── 验证报告.md                   覆盖范围、通过条件与实测统计
```

| 套件 | 覆盖内容 |
|---|---|
| 00_smoke | 正数点积及完整目的结果 |
| 01_directed | 负数、混合符号、零与边界值 |
| 02_random | 固定随机种子的输入自检 |
| 03_alias_v0 | 源/目的重叠及v0寄存器 |
| 04_pipeline | 连续流水和数据依赖 |
| 05_redirect | 分支恢复与错误路径处理 |
| 06_illegal | 不支持配置的非法指令处理 |
| 07_vadd | 既有向量加法回归 |

另有1个RVV等价性程序与6个性能配对程序，位于 [RVV基线目录](../3.2_RVV基线/README.md)，共同组成15项完整整核DiffTest。

本提交保留测试源码与结果汇总，原始日志、镜像及复现目录不提交。新运行结果在工程根目录的results/runs中生成，包含镜像、命令、emu.log.gz与result.json。覆盖和统计见[验证报告](验证报告.md)，运行命令统一见[stage3 README](../README.md)。
